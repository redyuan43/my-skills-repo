# LM Studio Brave Search CLI

This skill keeps LM Studio's Brave Search MCP usable without the GUI.

## Default Workflow

When this skill is invoked for question answering, prefer `ask` so the final answer is generated by a local model loaded in LM Studio:

```bash
bash /home/admin/github/my-skills-repo/lmstudio-brave-search-cli/scripts/lmstudio_brave_search.sh ask "美国和伊朗这两天的局势如何？是否会影响美股？"
```

For setup or validation, use:

```bash
bash /home/admin/github/my-skills-repo/lmstudio-brave-search-cli/scripts/lmstudio_brave_search.sh ensure
bash /home/admin/github/my-skills-repo/lmstudio-brave-search-cli/scripts/lmstudio_brave_search.sh test
```

Use `search` only when the user wants raw Brave search output:

```bash
bash /home/admin/github/my-skills-repo/lmstudio-brave-search-cli/scripts/lmstudio_brave_search.sh search "LM Studio official documentation"
```

## Behavior

- `ensure` enables Brave MCP by default in `~/.lmstudio/mcp.json` and the LM Studio MCP plugin bridge config.
- It installs the local MCP Node dependency `@modelcontextprotocol/sdk` if missing.
- It preserves the existing `~/.lmstudio/credentials/brave-search.env` key; pass `--api-key` only when a key is not already present.
- It defaults to the existing proxy in `brave-search.env`, otherwise `ALL_PROXY`, otherwise `socks5h://127.0.0.1:10808`.
- It restarts LM Studio after config changes unless `--no-restart` is passed.
- `ask` directly calls MCP `brave_web_search`, then sends the retrieved material to the local LM Studio model through `http://127.0.0.1:1234/v1/chat/completions`.
- The default local model identifier is `local-search-model`. Load `qwen3.6-35b-a3b-claude-4.6-opus-reasoning-distilled` with that identifier and `--context-length 100000`.
- `ask` defaults to `max_tokens=100000`; use `--max-tokens` only when a smaller budget is desired.
- `test` only calls MCP `brave_web_search`; it does not require opening LM Studio's chat UI.

## Useful Commands

```bash
bash scripts/lmstudio_brave_search.sh status
bash scripts/lmstudio_brave_search.sh ensure --no-restart
bash scripts/lmstudio_brave_search.sh restart
bash scripts/lmstudio_brave_search.sh test
bash scripts/lmstudio_brave_search.sh search "latest LM Studio MCP docs" --count 3
bash scripts/lmstudio_brave_search.sh ask "美国和伊朗这两天的局势如何？是否会影响美股？" --count 5
```

## Safety

Do not print the Brave API key. Report only whether a non-placeholder key exists, plus a short hash if needed.
