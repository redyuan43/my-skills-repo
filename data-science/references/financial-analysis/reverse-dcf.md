# 反向 DCF（Reverse DCF）模型详解与实操

**来源：** DCF 框架的逆向应用，用户实战方法论。
**版本：** 2.0 — 2026-05-14

---

## 1. 核心逻辑

**不计算「股票值多少钱」，而是计算「市场认为这个公司值多少钱背后的假设」。**

传统 DCF：输入假设 → 算出价值
反向 DCF：输入当前股价 → 算出隐含的增长率

将当前股价视为 DCF 公式中的已知数，反推市场隐含的关键假设（通常是高增长期增速 g1），然后与历史实际数据对比，判断市场定价是否合理。

---

## 2. 为什么需要反向 DCF？（三大痛点）

1. **避免「垃圾进，垃圾出」(GIGO)**：传统 DCF 对增长率、折现率极其敏感，稍微修改参数，估值天差地别。
2. **克服认知偏差**：分析师很容易对喜欢的公司过度乐观，对不喜欢的公司过度悲观。
3. **洞察市场情绪**：快速判断当前市场是理性的，还是陷入了疯狂或恐慌。

---

## 3. 两段式核心计算公式

反向 DCF 将未来分为两个阶段：**第 1-N 年的高增速阶段（隐含增长率 g）**，以及**第 N 年之后的永续增长阶段（永续增长率 gn）**。

```
当前企业价值 (EV) = Σ(t=1→N) [FCF₀ × (1+g)ᵗ / (1+WACC)ᵗ]
                   + [FCF₀ × (1+g)ᴺ × (1+gn) / (WACC - gn)] / (1+WACC)ᴺ
```

**已知量：** 当前 EV、基期 FCF₀、WACC、永续增长率 gn、预测期 N（通常 5 年）
**求解量：** 隐含增长率 g

---

## 3a. 参数预估方法论（关键）

反向 DCF 的输出质量取决于参数设定的透明度。**以下四个参数必须逐一说明预估依据，不得直接代入数字。**

### (1) WACC（加权平均资本成本）

WACC 必须与格林沃尔德 EPV 计算中的 WACC 保持一致，且需说明：

```
WACC = E/(E+D) × Ke + D/(E+D) × Kd × (1-t)

Ke = Rf + β × ERP

参数来源:
- Rf (无风险利率): FRED 10年期国债收益率 (中国: ~2.5%, 美国: ~4.3%)
- β (贝塔): 取自 yfinance 5年周线贝塔 (或可比公司β)
- ERP (股权风险溢价): 成熟市场 5-6%, A股 6-7%
- Kd (税后债务成本): 公司最近一期发债利率 × (1-有效税率)
- 资本结构: 按市值计算的目标资本结构
```

**示例（中国移动 600941）：**
```
Rf = 2.5%  (中国10Y国债)
β = 0.60   (电信运营商, 防御性)
ERP = 6.0%
Ke = 2.5% + 0.60 × 6.0% = 6.10%

Kd = 3.5% (央企发债利率约 3.0-4.0%)
t = 18%    (有效税率)
E/(E+D) = 93.3%  (权益占比)
D/(E+D) = 6.7%   (债务占比)

WACC = 93.3% × 6.10% + 6.7% × 3.5% × (1-18%)
     = 5.88%
```

### (2) g_terminal（永续增长率）

**永远不能超过名义GDP增速。** 标准取值：

| 场景 | 参考值 | 适用条件 |
|------|-------|---------|
| 发达国家成熟企业 | 2-3% | 稳定行业龙头 |
| 中国成熟企业 | 3-4% | 受益于GDP增速略高 |
| 衰退行业 | 0-1% | 营收零增长或下滑 |
| 高增长/未验证 | 不适用 | FCF 为负时反向 DCF 无效 |

### (3) g 的试算范围与搜索边界

二分法搜索范围必须根据行业特性设定：

| 行业类型 | 合理搜索范围 | 理由 |
|---------|------------|------|
| 成熟蓝筹/公共事业 | -10% ~ +10% | FCF 波动有限 |
| 消费/科技龙头 | -5% ~ +20% | 有一定增长空间 |
| 高增长科技 | 0% ~ +30% | 市场可能定价高增速 |
| 衰退/困境 | -30% ~ +5% | FCF 可能持续收缩 |

**搜索边界选择的逻辑：** 先跑一轮试算表（如 -6%, -4%, -2%, 0%, +2%...），观察每股价值是否跨越当前股价区间。如果所有试算值都高于/低于市价，说明基期 FCF 或 WACC 设定有问题，应返回检查参数，而非强行扩大搜索范围。

### (4) FCF₀（基期自由现金流）选择

| 选择方式 | 适用场景 | 风险 |
|---------|---------|------|
| 最近一年 FCF | 业务稳定、FCF 波动小 | 单年异常值会扭曲结果 |
| 3年加权平均 FCF | FCF 有周期性波动 | 平滑过度可能掩盖趋势变化 |
| 正常化 FCF | 有明显一次性项目 | 依赖分析师判断 |

**必须同时展示"基期 FCF"和"正常化 FCF"两套结果**，并说明选择理由。当两套结果互相矛盾时（如中国移动案例：2025年FCF¥759亿 → 隐含-2.8%，正常化FCF¥1,178亿 → 隐含-11.6%），意味着基期FCF存在一次性扰动，应以正常化值为辅参判读。

## 4. Python 自动化求解（推荐）

使用 scipy 的 root_scalar 自动反推隐含增长率：

```python
from scipy.optimize import root_scalar

def reverse_dcf_objective(g, ev, fcf0, wacc, gn, n=5):
    """计算基于特定增长率 g 的 DCF 估值与当前实际 EV 的差值"""
    pv_stage1 = 0
    for t in range(1, n + 1):
        fcf_t = fcf0 * ((1 + g) ** t)
        pv_stage1 += fcf_t / ((1 + wacc) ** t)

    # 终值 (Terminal Value)
    fcf_n = fcf0 * ((1 + g) ** n)
    tv = (fcf_n * (1 + gn)) / (wacc - gn)
    pv_tv = tv / ((1 + wacc) ** n)

    return (pv_stage1 + pv_tv) - ev

# 使用根寻找算法求解
result = root_scalar(
    reverse_dcf_objective,
    args=(current_ev, base_fcf, wacc_rate, perpetual_g, forecast_years),
    bracket=[-0.5, 0.8]  # 假设隐含增长率在 -50% 到 80% 之间
)

if result.converged:
    print(f"隐含未来 {forecast_years} 年年化 FCF 增长率: {result.root * 100:.2f}%")
```

### CFO 分析中的推荐实现

当 `scipy` 不可用时，使用以下无依赖的反向 DCF：

```python
def reverse_dcf(g1, g_terminal=0.03, wacc=0.09, fcf0=100, shares=10, 
                excess_cash=0, debt=0):
    """计算给定增长率下的每股价值"""
    pv = 0.0
    fcf = fcf0
    for yr in range(1, 6):
        fcf *= (1 + g1)
        pv += fcf / ((1 + wacc) ** yr)
    tv = fcf * (1 + g_terminal) / (wacc - g_terminal)
    pv_tv = tv / ((1 + wacc) ** 5)
    ev = pv + pv_tv
    eq = ev + excess_cash - debt
    return eq / shares

# 试算不同增长率
for g1 in [-0.05, -0.02, 0.0, 0.02, 0.05, 0.08, 0.10]:
    ps = reverse_dcf(g1, ...)
    print(f"g1={g1*100:+.0f}% → 每股价值 ¥{ps:.2f}")

# 或使用二分法求解精确隐含增速
lo, hi = -0.20, 0.20
for _ in range(40):
    mid = (lo + hi) / 2
    if reverse_dcf(mid, ...) > current_price:
        lo = mid
    else:
        hi = mid
implied_g = (lo + hi) / 2
```

## 5. 结果判读方法

| 对比 | 结论 |
|------|------|
| 隐含增速 ≈ 历史实际增速 | 市场定价合理 |
| 隐含增速 >> 历史实际增速 | 市场过度乐观（警惕泡沫） |
| 隐含增速 << 历史实际增速 | 市场过度悲观（可能存在机会） |

### 判读三维度

1. **合理性检验 (Sanity Check)**：计算出的增长率是否与公司历史、行业龙头水平相符？成熟行业出现 30% 隐含增长率 → 通常意味着高估。
2. **敏感性与市场假设**：反向 DCF 告诉你市场在「赌」什么。某科技股的股价，是否需要靠新业务暴增才能支撑这个增速？
3. **判断买卖时机**：如果隐含增长率很低（如 2%），且公司仍在健康成长，说明有较高安全边际。

## 6. 模型适用性与局限

| 维度 | 评估 |
|------|------|
| ✅ **最适用** | 现金流稳定、成熟、可预测的蓝筹股（消费巨头、公共事业） |
| ❌ **不适用** | 负现金流初创公司、强周期性行业、高债务或频繁并购的公司 |
| ✅ **优势** | 揭示市场预期，强迫思考商业本质，而非死扣具体估值数字 |
| ❌ **局限** | 依然依赖 WACC 的设定；对 FCF 负值的公司完全失效 |

### 在 CFO 分析中的角色

反向 DCF 是**三模型交叉验证的第三极**，定位为定性参考而非精确估值工具：

```
格林沃尔德（资产锚定） → 麦肯锡（增长价值） → 反向DCF（市场心态探测）
```

当 FCF 为负时，反向 DCF 不适用。此时改用**隐含 PE 反推法**：`市值 ÷ 远期 PE = 隐含净利润`，判断市场定价是否合理。
