# 电信运营商分析特化规则

> 适用场景：分析中国移动、中国电信、中国联通等电信运营商时适用。
> 创建于：2026-05-13，基于中国移动(600941)实战分析经验。

## 1. 维护性 CapEx 假设 — EPV 最脆弱的假设

运营商是资本密集型企业（CapEx/营收 15-25%），EPV 对维护性 CapEx 占比**极度敏感**。

### 中国移动案例

| 假设 | 维护CapEx | EPV/股 | vs ¥97.89 |
|------|----------|--------|-----------|
| D&A > 总CapEx → 无需调整 | ¥0 (已覆盖) | ¥100.37 | +2.5% |
| 维护CapEx = 总CapEx的65% | ¥1,020亿 | ¥65.04 | -33.6% |
| 维护CapEx = D&A×1.3 | ¥2,280亿 | ¥56.14 | -42.6% |

> ⚠️ EPV 的核心脆弱点：**当 D&A 与 CapEx 的对比关系模糊时，EPV 结果可以在合理范围内上下摆动 40%+。** 不要只给一个 EPV 数字——必须展示敏感性范围。

### 电信运营商维护CapEx估算规则

- **黄金标准：** 查阅港股年报的"折旧与摊销"行（HK GAAP 单独披露）
- **A 股参考：** A 股利润表的"折旧摊销"通常仅含无形资产摊销，**严重低估**真实 D&A
- **经验法则：** 成熟期运营商维护CapEx ≈ D&A × 1.0-1.2（因设备老化维护成本上升）
- **建设期例外：** 4G→5G→6G 建设高峰年，增长CapEx占比可达 40-50%
- **信号检测：** 当 D&A(港股) < 总CapEx 时，超出部分为增长CapEx

## 2. D&A 数据源选择 — 永远不要只信 A 股

### A+H 双地上市场景

| 场景 | 正确做法 |
|------|---------|
| 仅有 A 股数据 | 从资产负债表推算：期初PP&E原值 + CapEx - 期末PP&E原值 = 年折旧(近似) |
| A+H 均有数据 | **优先使用港股披露的"折旧与摊销"行**（完整，含固定资产+无形资产） |
| 仅有 H 股数据 | 直接用，HK GAAP 披露更完整 |

**从 A 股推算折旧的 Python 代码：**
```python
# 从固定资产原值变动推算
pp_begin = 22946  # 上年末原值
pp_end = 23617    # 本年末原值
capex = 1570      # 购建固定/无形资产支付的现金
disposals = 0     # 处置，可从附注获取
depreciation = pp_begin + capex - disposals - pp_end
```

## 3. 现金流分析特殊注意事项

运营商 OCF 波动大，不能单看一年 FCF：

- **FCF 波动原因：** 税费支付节奏（大额集中支付）、应收账款季节性
- **正常化 FCF：** 取 3-5 年滚动平均更可靠
- **信号规律：** OCF 持续下降 + 应收账款持续上升 = 真实恶化信号
- **反向 DCF 陷阱：** 若以异常低 FCF 年份为基准，反向 DCF 会高估市场悲观程度

## 4. 6G 投资周期预警

- 预计 2028-2030 年启动 6G 建设期
- CapEx 可能再次跳升 30-50%（参考 4G→5G 周期）
- 这将显著压低 FCF 和 ROIC
- 估值时必须标注"CapEx 周期性回升风险"

## 5. 运营商特有的估值指标

标准框架外，电信运营商应额外关注：

| 指标 | 说明 | 健康范围 |
|------|------|---------|
| CapEx/营收 | 资本开支强度 | <20%（成熟期） |
| FCF/净利润 | 现金转化率 | >80% |
| EV/EBITDA | 企业价值倍数 | <6x（价值区域） |
| 分红支付率 | 利润用于分红比例 | 60-80%（可持续） |
| 应收账款/营收 | 回款周期指示 | <8% |

## 6. 与标准 Greenwald 框架的偏差

运营商的分析偏差与 SaaS 企业**方向相反**：

| 偏差 | SaaS 企业 | 电信运营商 |
|------|----------|-----------|
| ARV | 严重低估（无形资产不入表） | 基本合理或略高估（回收率争议大） |
| EPV | 高增长导致权重争议 | 维护CapEx假设导致大幅波动 |
| FV | 高增长价值是核心 | 增长价值有限（低增长行业） |
