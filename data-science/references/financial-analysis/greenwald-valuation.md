# 格林沃尔德三要素估值法

**来源：** Bruce Greenwald, *Value Investing: From Graham to Buffett and Beyond*

---

## 1. 核心理念

**三要素独立与市价对比，不求和、不合并为单一内在价值。**

```
要素① ARV（资产重置价值） ← vs 市价 → 一级安全边际（深度价值）
要素② EPV（收益能力价值） ← vs 市价 → 二级安全边际（收益覆盖价格）
要素③ 预期收益率  ← 仅当 EPV > ARV 时执行 → 判定市场定价是否合理
```

---

## 2. 要素①：ARV — 资产重置价值

### 2.1 流动资产调整

| 科目 | 调整规则 |
|------|---------|
| **现金与等价物** | 运营现金 = 营收 × 1%；超额现金 = 账面现金 - 运营现金。超额现金在运营ARV中剥离，股权转换时再加回 |
| **应收账款** | 调整后 = 账面A/R + 坏账准备（竞争对手需承担同等坏账成本） |
| **存货** | LIFO: 账面+LIFO准备金；FIFO: 直接使用账面值 |

### 2.2 长期资产调整

| 科目 | 调整规则 |
|------|---------|
| **固定资产(PP&E)** | **严禁使用 Net PP&E。** 使用 Gross PP&E + 通胀调整 - 技术过时贬值 |
| **商誉** | 强制赋值为 0 |
| **隐性无形资产** | R&D资本化 + 渠道成本 + 培训成本。过去数年被费用化的部分加回 |

### 2.3 负债扣减

```
运营 ARV = (调整后流动资产 + 调整后长期资产) - 自发性负债(应付/预收/应付工资/应交税费)
  ⚠️ 运营ARV中严禁扣除带息债务

股权 ARV = 运营 ARV + 超额现金 + 非核心投资 - 带息债务 - 其他特定负债
```

### 2.4 报告格式

必须展示**3年对比表**，逐项资产列示。

---

## 3. 要素②：EPV — 收益能力价值

### 3.1 收益流清洗

| 步骤 | 操作 |
|------|------|
| 1 | **起点 = EBIT**。剔除所有利息收入与利息支出（否则后续加回现金时双重计算） |
| 2 | **周期平滑**：平滑营收 × 5-7年平均营业利润率 |
| 3 | **隐蔽利润加回**（零增长假设）：SG&A中获客支出(通常25%) + R&D中新品支出 → 加回到利润 |
| 4 | **NOPAT** = 正常化EBIT × (1 - 平均有效税率) |

### 3.2 CapEx 手术

EPV **仅扣除维持性 CapEx**：

```
增长性 CapEx = 营收增长额 × (PP&E/营收平均比率)
维持性 CapEx = 总CapEx - 增长性CapEx

调整后收益 = NOPAT + 税后超额折旧 - 维持性CapEx
```

### 3.3 EPV 终值

```
经营资产 EPV = 调整后收益 / WACC
  WACC 在8%-12%之间

股权 EPV = 经营资产EPV + 超额现金 + 非经营资产 - 有息债务 - 少数股东权益
```

### 3.4 报告格式

必须使用 **3年加权平均 NOPAT**（周期行业5:3:2，稳定消费4:3:3），展示 **WACC敏感性表**。

## 4. 要素③：护城河验证与预期收益率

### 4.1 护城河交叉验证

| EPV vs ARV | 判定 | 动作 |
|------------|------|------|
| EPV < ARV | 价值毁灭 | 终止买入，进入做空/清算分析 |
| EPV ≈ ARV | 效率竞争，无护城河 | 仅当市值 < EPV 时买入 |
| EPV > ARV | **存在特许权(Franchise)** | 启动预期收益率计算 |

### 4.2 预期收益率模型

```
基准预期回报率 = 现金收益回报 + 内生增长回报 + 主动再投资回报 - 特许权衰减

现金收益回报    = (正常化盈余 / 市价) × 派息率
内生增长回报    = 历史长期营收增速（上限 GDP+3%）
主动再投资回报  = (留存收益/市价) × 价值因子(ROIC>WACC?1:0)
特许权衰减      = 72 / 护城河半衰年数
```

---

## 5. 决策树

```
① 市值 < 股权ARV？ → 一级安全边际（深度价值）
② ELSE IF 市值 < 股权EPV and EPV >= ARV？ → 二级安全边际
③ ELSE IF EPV > ARV and 预期回报率 > WACC+衰减？ → 三级安全边际
④ ELSE → 无安全边际 / 价值陷阱
```
