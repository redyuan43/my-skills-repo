# 行业数据陷阱 — 财报数据获取中的已知问题

本文件记录从 yfinance 及其他数据源获取特定行业财务数据时已知的陷阱和调整规则。

## 银行（A 股 + 美股）

### FCF 完全不可使用

**问题：** 银行的"经营现金流"（Operating Cash Flow）主要是存款流入与贷款流出的轧差额，与工业企业的"经营创造现金"概念完全不同。

**表现：** 兴业银行 2025 年经营现金流 ¥6537亿，2024 年却是 -¥2373亿。这不是经营恶化，而是存款波动的结果。

**规则：** 银行分析中**永远不使用 FCF**。银行的真实可分配利润按以下公式计算：

```
真实可分配利润 = 净利润 × (1 - 最低资本留存率)
最低资本留存率 ≈ 30%（受监管要求约束）
股东收益率 ≈ (净利润 × 分红率) / 市值
```

### ROIC = ROE

银行不适用 `NOPAT / 投入资本` 的标准 ROIC 公式。银行的"投入资本"就是股东权益。银行的 ROIC 直接退化为 ROE：

```
ROE = 净利润 / 平均股东权益
```

### 资产质量关注点

银行的 PB<1 是常态（不是低估信号）。需要关注：

- **不良贷款率 (NPL)：** 官方数据可能低于真实值。关注类贷款 + 逾期贷款往往是 NPL 的 1.5-2x
- **拨备覆盖率：** 越低说明资产质量缓冲越薄
- **核心一级资本充足率 (CET1)：** 反映银行的资本缓冲

## 水电站 / 公用事业（A 股）

### 低 ROIC 是常态而非问题

**问题：** 长江电力 ROIC=6.8%，看起来很低。

**解释：** 水电站是极端重资产。三峡大坝造价超过 ¥2000亿，这些资产已经建成并产生稳定现金流。分母（投入资本）巨大但不意味着生意差。**边际资本回报率是 100%**（多发一度电几乎全是利润）。

**规则：** 对水电站等已建成基础设施，ROIC 参考意义有限。关注：
- **经营现金流稳定性（多年均值）**
- **FCF / 营收比**（长江电力: 53.5%）
- **债务偿还进度**

### 经营现金流包含重大一次性项目

水电站的"资本开支"包含常规维护（小）和重大更新（大）。需区分：
- 维持性 Capex（正常年份 ¥5-10B）
- 扩张性 Capex（新电站建设，¥50B+）

## A 股公司普遍缺失的数据

通过 yfinance 获取 A 股数据时以下字段几乎全为 N/A：

| 字段 | 原因 | 替代方案 |
|------|------|---------|
| SBC（股权激励） | A 股股权激励以限制性股票为主，yfinance 不映射 | 从年报附注查找 |
| 回购 | A 股回购极少，且不通过美股托管通道 | 从港交所/上交所公告查找 |
| 分红 | A 股分红不通过 DTCC，yfinance 无数据 | 从 `info['dividendYield']` 反推 |
| 应收/应付细节 | yfinance 资产负债表对中概/A股的科目映射不全 | 从年报中查找 |

## yfinance 股息率字段的格式差异

| 市场 | 格式 | 示例 | 说明 |
|------|------|------|------|
| 美股 | 小数 | `0.0038` 表示 0.38% | 直接可用 |
| A 股 | 百分比值 | `4.06` 表示 4.06% | 需要除以 100 才与美股统一 |
| 港股 | 不定 | 可能为小数或百分比 | 需检查后处理 |

## Web 搜索兜底的局限性

自动化浏览器搜索（Bing/Google/Baidu）经常会遇到：

- Cloudflare CAPTCHA 验证
- 滑块验证码（"请验证您是真人"）
- 访问频率限制

**策略：** 优先通过 yfinance 获取结构化数据。仅对必须但缺失的字段（如管理层指引、竞品数据）启动浏览器搜索。如果被 CAPTCHA 拦截，在报告中明确标记为"待补充"而非强行搜索。
