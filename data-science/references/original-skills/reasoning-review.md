# 思考链展现 — Reasoning Trace

## 核心纪律（重要 — 历史教训总结）

以下规则从2026-05-03 BZ现金数据错误和市值换算错误中总结，必须严格遵守：

1. **所有计算必须用 Python execute_code 或终端命令执行**，禁止在回复正文中脑算任何金额换算、比率或估值。\n2. **净现金/市值 > 80% 时自动触发币种一致性检查**：确认现金所在币种和市值币种是否一致。混用 CNY/USD 是此类异常最常见的原因。\n3. **每个数字必须附带币种前缀（¥/$）和亿级单位**。禁止裸数字。\n4. **数量级验证**：$6.2B ≈ ¥450亿（非¥45亿）。换算后检查数字位数（¥45亿 vs ¥450亿差10倍）。\n5. **三模型估值记录规则**：思考链中必须分别记录格林沃尔德(模型A)、超额回报折现(模型B)、反向DCF(模型C)三种方法的计算过程和输入参数，对应投资备忘录的5a-5g节。不得仅记录单一模型。

## 定位

此 skill 是 **financial-analysis 的伴随技能**。每次生成投资备忘录时，同步生成一份 `reasoning_review_[股票代码]_[公司名]_[日期]_V[版本].md`，记录从数据采集到最终结论的完整思考链，确保每个判断都可追溯、可复现、可质疑。

## 触发条件

- 每次调用 cfo-deep-dive 生成投资备忘录后**自动执行**
- 用户明确要求 "展示思考链" 或 "显示推理过程"

## 输出文件

写入 `~/.hermes/skills/data-science/out/out_reports/` 目录下，命名为 `reasoning_trace_[股票代码]_[公司名]_[日期]_V[版本].md`

版本号与同标的的 investment_memo 和 critical_review 保持一致。

## 3. 派生指标计算过程

### ROIC
```
NOPAT = 营业利润¥51.9亿 × (1-15%税率) = ¥44.1亿
投入资本 = 有息负债¥70.6亿 + 权益¥94.2亿 - 现金¥56.8亿 = ¥108.0亿
ROIC = ¥44.1亿 / ¥108.0亿 = 40.8%
```

### WACC 设定依据
```
中国无风险利率 ≈ 2.0%（10年期国债）
Beta = 0.295（来自 yfinance info）
股权风险溢价 = 6%（A股消费品）
WACC = 2% + 0.295 × 6% = 3.8%（太低，不现实）

→ 实际采用 WACC = 8%（修正后），理由：
  中国消费品企业的实际融资成本不低于6-8%
  公司Beta偏低（0.295）但小市值溢价应上调
